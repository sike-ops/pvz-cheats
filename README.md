# Pvz Cheats

Developed for the latest version of PvZ from Steam

Hack menu options:
- Add 100 sun
- Zero cost of plants
- Zero wait for planting
- Fast shooting plants
- Immortal plants
- Instakill zombies

![pic](images/pic01.png)

### Build

Requires x86-32 toolchain since PvZ is 32-bit game

```cmd
cmake -B build
cmake --build build
```
